# เอกสารความต้องการ

## 1. ภาพรวมแอปพลิเคชัน

- **ชื่อแอปพลิเคชัน**: ครูติว AI
- **คำอธิบายแอปพลิเคชัน**: แอปพลิเคชันมือถือสำหรับช่วยติวการบ้านนักเรียนไทยระดับชั้น ป.4-ม.3 ในวิชาคณิตศาสตร์ วิทยาศาสตร์ และภาษาอังกฤษ โดยให้คำแนะนำและวิธีคิดแบบเป็นลำดับขั้นตอนด้วยระบบ AI

## 2. ผู้ใช้และสถานการณ์การใช้งานหลัก

- **กลุ่มเป้าหมาย**: นักเรียนระดับชั้นประถมศึกษาปีที่ 4 ถึง มัธยมศึกษาปีที่ 3 ในประเทศไทย
- **สถานการณ์การใช้งานหลัก**: นักเรียนถ่ายภาพหรืออัปโหลดภาพการบ้าน เลือกรายวิชา และรับคำแนะนำวิธีคิดทีละขั้นตอนเป็นภาษาไทยเพื่อฝึกคิดแก้ปัญหาด้วยตนเอง รวมถึงสามารถตั้งค่า API Key ส่วนตัวเพื่อใช้งานได้

## 3. โครงสร้างหน้าจอและข้อกำหนดการทำงาน

### โครงสร้างหน้าจอ

```
1. หน้าติวการบ้าน (Main Tutor Screen)
2. หน้าประวัติ (History Screen)
3. หน้าตั้งค่า (Settings Screen)
```

### รายละเอียดหน้าจอ

#### 1. หน้าติวการบ้าน (Main Tutor Screen)
- **การถ่ายภาพหรืออัปโหลดรูปภาพการบ้าน**:
  - รองรับการถ่ายภาพจากกล้องของอุปกรณ์ หรือเลือกภาพจากคลังรูปภาพ
  - แสดงภาพตัวอย่างที่ถ่ายหรือเลือกก่อนกดยืนยัน
- **การเลือกวิชา**:
  - ตัวเลือก 3 วิชาหลัก ได้แก่ คณิตศาสตร์, วิทยาศาสตร์ และภาษาอังกฤษ
- **ปุ่มดำเนินการ**:
  - ปุ่ม [ให้ครู AI อธิบาย] สำหรับส่งภาพและวิชาที่เลือกไปยังระบบประมวลผล
- **ส่วนแสดงผลลัพธ์**:
  - แสดงคำแนะนำและแนวทางคิดทีละขั้นตอนจาก AI เป็นภาษาไทย

#### 2. หน้าประวัติ (History Screen)
- **รายการประวัติการถามการบ้าน**:
  - แสดงรายการคำถามย้อนหลัง เรียงตามลำดับเวลา
  - แสดงรูปขนาดย่อ (Thumbnail), ป้ายกำกับวิชา และขั้นตอนคำอธิบายของ AI ที่เคยได้รับ
  - สามารถกดดูรายละเอียดคำอธิบายย้อนหลังได้

#### 3. หน้าตั้งค่า (Settings Screen)
- **การจัดการ Gemini API Key**:
  - ช่องกรอก Gemini API Key พร้อมปุ่มสลับการซ่อน/แสดงคีย์
  - ปุ่มบันทึกคีย์ (เก็บไว้เฉพาะในเครื่องของผู้ใช้)
  - ปุ่มลบคีย์ที่บันทึกไว้
  - แสดงสถานะปัจจุบันว่ามีการบันทึกคีย์ส่วนตัวไว้แล้วหรือไม่
  - ข้อความแจ้งเตือนให้ผู้ใช้ทราบว่า หากไม่ได้ใส่คีย์ ระบบจะใช้คีย์สำรองของแอปพลิเคชันโดยอัตโนมัติ
- **การทดสอบการเชื่อมต่อ**:
  - ปุ่มทดสอบการเชื่อมต่อ API Key เพื่อตรวจสอบความถูกต้องและการใช้งานได้จริง พร้อมแสดงผลลัพธ์สำเร็จหรือข้อผิดพลาดเป็นภาษาไทย
- **ลิงก์ภายนอก**:
  - ลิงก์สำหรับเปิดไปยังหน้า Google AI Studio เพื่อรับ API Key ฟรี

## 4. กฎทางธุรกิจและตรรกะหลัก

1. **การเรียกใช้งาน API Key**:
   - ระบบจะตรวจสอบการมีอยู่ของ API Key ที่บันทึกไว้ในเครื่องของผู้ใช้เป็นลำดับแรก
   - หากมีคีย์ของผู้ใช้ ระบบจะนำคีย์ดังกล่าวไปใช้ในการประมวลผลคำขอติวการบ้านและการทดสอบการเชื่อมต่อ
   - หากไม่มีการบันทึกคีย์ของผู้ใช้ ระบบจะสลับไปใช้คีย์สำรองของแอปพลิเคชันโดยอัตโนมัติ
2. **ความปลอดภัยของข้อมูลคีย์**:
   - คีย์ของผู้ใช้จะถูกจัดเก็บไว้เฉพาะในพื้นที่จัดเก็บข้อมูลภายในเครื่องของอุปกรณ์เท่านั้น
   - ไม่มีการส่งคีย์ไปจัดเก็บที่ฐานข้อมูลส่วนกลาง และไม่มีการแสดงคีย์แบบเต็มรูปแบบหลังบันทึกแล้ว
3. **การสร้างคำอธิบายของ AI (Pedagogical Rules)**:
   - รูปแบบการสอนแบบ Socratic: ไม่เฉลยคำตอบสุดท้ายโดยตรง แต่ให้คำแนะนำเป็นขั้นตอนในการคิด (3-5 ขั้นตอน) พร้อมประโยคให้กำลังใจ
   - หากภาพที่อัปโหลดไม่ใช่เนื้อหาการบ้าน ระบบจะแสดงข้อความแจ้งเตือนอย่างสุภาพเป็นภาษาไทยว่ารองรับเฉพาะการช่วยทำการบ้านเท่านั้น
4. **การบันทึกประวัติ**:
   - บันทึกภาพขนาดย่อ, วิชา และขั้นตอนคำอธิบายลงในระบบประวัติเมื่อได้รับคำตอบสำเร็จ

## 5. กรณีผิดปกติและขอบเขตเงื่อนไข

| เหตุการณ์ | เงื่อนไข | พฤติกรรมของระบบ |
| :--- | :--- | :--- |
| ภาพไม่เกี่ยวข้องกับการบ้าน | ภาพที่ส่งไปไม่มีเนื้อหาการบ้าน | แสดงข้อความแจ้งเตือนว่ารองรับเฉพาะคำถามการบ้าน |
| ข้อมูลไม่ครบถ้วน | ผู้ใช้กดยืนยันโดยไม่ได้เลือกรูปภาพหรือวิชา | แสดงข้อความแจ้งให้ผู้ใช้ถ่าย/เลือกภาพและระบุวิชาก่อน |
| โควตาเต็ม (HTTP 429) | โควตาของ API สิ้นสุด | แสดงข้อความ [หมดโควตาฟรีรายวันแล้ว] |
| คีย์ไม่ถูกต้อง (HTTP 400) | คีย์ไม่ถูกต้องหรือถูกลบ | แสดงข้อความ [key ไม่ถูกต้อง] |
| API ไม่เปิดใช้งาน (HTTP 403) | API ยังไม่ได้รับอนุญาตหรือปิดใช้งาน | แสดงข้อความ [API ยังไม่เปิดใช้งาน] |
| ทดสอบการเชื่อมต่อไม่สำเร็จ | คีย์ทดสอบไม่ถูกต้องหรือใช้งานไม่ได้ | แสดงข้อความแจ้งผลการทดสอบล้มเหลวเป็นภาษาไทย |

## 6. เกณฑ์การยอมรับ

1. ผู้ใช้สามารถถ่ายภาพหรือเลือกภาพ และเลือกวิชา (คณิตศาสตร์, วิทยาศาสตร์, ภาษาอังกฤษ) เพื่อส่งให้ AI อธิบายได้
2. ระบบแสดงคำอธิบายแบบเป็นขั้นตอนภาษาไทยโดยไม่เฉลยคำตอบสุดท้ายโดยตรง
3. รายการคำถามและคำอธิบายที่สำเร็จถูกบันทึกและสามารถเปิดดูได้ในหน้าประวัติ
4. ผู้ใช้สามารถกรอก บันทึก ลบ และทดสอบ Gemini API Key ในหน้าตั้งค่าได้สำเร็จ
5. ระบบแสดงสถานะการบันทึกคีย์ และสลับไปใช้คีย์สำรองของแอปพลิเคชันโดยอัตโนมัติเมื่อไม่มีคีย์ของผู้ใช้
6. การทดสอบการเชื่อมต่อคีย์และการแจ้งเตือนข้อผิดพลาดทั้งหมดแสดงผลเป็นภาษาไทยอย่างถูกต้อง

## 7. สิ่งที่ไม่รวมในขอบเขตเวอร์ชันนี้ (MVP)

- การแปลงข้อความเป็นเสียงอ่านคำอธิบาย
- ระบบจัดการโปรไฟล์และรูปประจำตัวผู้ใช้
- การแก้ไขหรือจัดหมวดหมู่รายการประวัติย้อนหลังด้วยตนเอง
